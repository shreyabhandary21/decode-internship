# DecodeLabs Project 1 - Responsive Frontend Interface

This project is a complete beginner-friendly responsive frontend implementation for Project 1.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Main requirements covered
- Semantic HTML5 structure
- Responsive mobile-first layout
- CSS Grid for page-level layouts
- Flexbox for components/navigation
- Basic JavaScript interaction
- Clean, user-friendly interface
- Responsive navigation menu
- Add, complete and delete tasks
- Completion progress indicator
- Local browser persistence

## How to run

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html`.

No installation or framework is required.

## Suggested folder structure

DecodeLabs_Project1_Responsive_Frontend/

├── README.md
├── css/

## Project reference

The implementation follows the uploaded Project 1 brief: a responsive frontend interface using HTML, CSS and basic JavaScript, with responsive layouts and clean UI. The reference also emphasizes semantic HTML, Grid/Flexbox, mobile-first design and avoiding frameworks for this fundamentals project.
